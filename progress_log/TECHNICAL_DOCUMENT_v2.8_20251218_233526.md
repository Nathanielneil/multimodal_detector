## 1. 项目概述

### 1.1 项目简介

**多模态无人机集群控制系统** 是一个基于 PySide6 的桌面应用程序，通过融合多种人机交互方式（语音、手势、图像、触屏）实现对无人机集群的直观控制。

**v2.8 版本说明**: 由于 L2 姿态动力学模型在实际测试中出现严重的姿态不稳定问题（无人机持续倾斜震荡，无法保持编队），已回滚至稳定的 L1 基础动力学模型。

### 1.2 核心特性

| 特性 | 描述 | 状态 |
|------|------|------|
| **四模态输入** | 语音识别 (Whisper)、手势识别 (MediaPipe)、图像识别 (YOLOv8)、触屏手绘 | ✅ |
| **无人机指令映射** | 手势→起飞/降落/悬停/编队/高度控制/向前飞行 | ✅ |
| **手绘编队控制** | 绘制三角形/正方形/圆形/五角星切换编队 | ✅ |

1. **编队飞行时无人机持续倾斜**，无法保持水平稳定
2. **姿态震荡无法收敛**，即使到达目标位置后仍持续摇摆

2. **DroneModel._update_transform**: 移除姿态倾斜可视化
3. **get_attitude / get_attitude_deg**: 返回零值

## 3. L2 动力学失败分析

### 3.1 问题现象

测试时观察到的具体问题：

| 现象 | 描述 |
|------|------|
| **持续倾斜** | 无人机在编队飞行时始终保持倾斜状态，无法恢复水平 |
| **姿态震荡** | Roll/Pitch 角度在目标附近持续震荡，无法收敛 |
| **编队变形** | 由于各无人机姿态不一致，编队形状严重变形 |

### 3.2 根因分析

#### 3.2.1 控制器参数问题

**原始参数**:
```python
# 位置控制 (外环)
pos_kp = 2.0      # 位置比例增益
pos_kd = 1.5      # 位置微分增益

# 姿态控制 (内环)
att_kp = 8.0      # 姿态比例增益
att_kd = 2.0      # 姿态微分增益 ← 阻尼不足
att_ki = 0.5      # 姿态积分增益 ← 积分累积过快
```

**问题分析**:

1. **阻尼系数不足 (att_kd = 2.0)**
   - 姿态控制的阻尼项过小，无法有效抑制角速度
   - 导致姿态响应过冲，产生震荡

2. **积分增益过大 (att_ki = 0.5)**
   - 积分项累积过快，导致稳态偏差
   - 即使误差为零，积分项仍保持非零值，使姿态持续偏移

3. **位置增益过激进 (pos_kp = 2.0)**
   - 位置误差产生过大的期望姿态角
   - 外环响应过快，内环跟不上

#### 3.2.2 尝试的调参方案

| 尝试 | 参数修改 | 效果 |
|------|----------|------|
| 1 | att_kd: 2.0 → 5.0 | 震荡减小但仍存在 |
| 2 | att_ki: 0.5 → 0.1 | 积分累积减少 |
| 3 | pos_kp: 2.0 → 1.2 | 响应变慢 |
| 4 | 接近目标时衰减期望姿态 | 部分改善 |

**最终结论**: 单纯调参无法彻底解决问题，需要更深层次的架构优化。

#### 3.2.3 架构层面的问题

1. **双环控制带宽匹配问题**
   - 外环 (位置) 和内环 (姿态) 的带宽没有合理分离
   - 理论上内环带宽应为外环的 5-10 倍
   - 当前实现中两者耦合过紧

2. **欧拉角奇异性**
   - 使用欧拉角表示姿态存在万向节锁问题
   - 虽然实现了保护逻辑，但在极端情况下仍可能出问题

3. **积分抗饱和不完善**
   - 虽然有积分限幅，但限幅值 (0.3 → 0.1) 仍可能过大
   - 缺乏更智能的积分抗饱和机制 (如条件积分、反计算)

4. **缺乏前馈控制**
   - 纯反馈控制响应滞后
   - 缺少基于目标轨迹的前馈项

## 4. 当前动力学模型 (L1)

### 4.1 模型概述

| 属性 | 值 |
|------|-----|
| 状态维度 | 6 DOF (位置 + 速度) |
| 控制方式 | PD 位置控制 |
| 积分方法 | 半隐式欧拉 |
| 稳定性 | ✅ 稳定 |

### 4.2 状态空间

```
状态向量 x = [x, y, z, vx, vy, vz]ᵀ

位置状态 (世界坐标系):
- x, y, z     : 位置 (m)
- vx, vy, vz  : 速度 (m/s)
```

### 4.3 动力学参数

| 参数 | 符号 | 默认值 | 说明 |
|------|------|--------|------|
| 质量 | m | 1.5 kg | 无人机质量 |
| 最大推力 | F_max | 30.0 N | ~2g |
| 最大速度 | v_max | 5.0 m/s | 速度限制 |
| 阻力系数 | c_d | 0.3 | 线性阻力 |
| 重力加速度 | g | 9.81 m/s² | - |
| 位置增益 | kp | 2.0 | PD 控制 |
| 速度增益 | kd | 1.5 | PD 控制 |

### 4.4 动力学方程

```
控制加速度:
a_cmd = kp * (target - position) - kd * velocity

加速度限幅:
|a_xy| ≤ max_accel
a_z ∈ [-max_accel_down, max_accel]

阻力:
a_drag = -c_d * velocity

总加速度:
a_total = a_cmd + a_drag

积分 (半隐式欧拉):
velocity_new = velocity + a_total * dt
position_new = position + velocity_new * dt
```

### 4.5 代码实现

```python
class QuadrotorDynamics:
    """L1 四旋翼动力学模型 (Sim2Real) - 基础版本"""

    def __init__(
        self,
        mass: float = 1.5,
        max_thrust: float = 30.0,
        max_velocity: float = 5.0,
        drag_coeff: float = 0.3,
        gravity: float = 9.81,
    ):
        self.mass = mass
        self.max_thrust = max_thrust
        self.max_velocity = max_velocity
        self.drag_coeff = drag_coeff
        self.gravity = gravity

        self.max_accel = max_thrust / mass - gravity
        self.max_accel_down = max_thrust / mass + gravity

        self.position = np.array([0.0, 0.0, 0.0])
        self.velocity = np.array([0.0, 0.0, 0.0])
        self._target_position = np.array([0.0, 0.0, 0.0])

        self.kp = 2.0
        self.kd = 1.5

    def step(self, dt: float, external_accel: np.ndarray = None) -> np.ndarray:
        if external_accel is not None:
            accel = external_accel.copy()
        else:
            pos_error = self._target_position - self.position
            accel = self.kp * pos_error - self.kd * self.velocity

        # 加速度限幅
        accel_xy = accel[:2]
        accel_xy_norm = np.linalg.norm(accel_xy)
        if accel_xy_norm > self.max_accel:
            accel[:2] = accel_xy / accel_xy_norm * self.max_accel
        accel[2] = np.clip(accel[2], -self.max_accel_down, self.max_accel)

        # 阻力
        drag = -self.drag_coeff * self.velocity
        total_accel = accel + drag

        # 半隐式欧拉积分
        self.velocity = self.velocity + total_accel * dt

        # 速度限幅
        speed = np.linalg.norm(self.velocity)
        if speed > self.max_velocity:
            self.velocity = self.velocity / speed * self.max_velocity

        self.position = self.position + self.velocity * dt
        return self.position
```

## 12. 经验教训与后续建议

### 12.1 L2 失败的核心教训

1. **控制器设计需要理论支撑**
   - 双环控制需要合理的带宽分离
   - PID 参数不能靠猜测，需要系统辨识或理论计算

2. **测试应该渐进式**
   - 应先在单机、静态条件下验证姿态控制器
   - 再逐步加入编队、避障等复杂场景

3. **仿真验证的重要性**
   - 应先在 MATLAB/Simulink 等工具中验证控制器设计
   - 再移植到实际代码中

### 12.2 重新实现 L2 的建议

若后续需要重新实现 L2 姿态动力学，建议：

```python
pos_kd = 1.2      #

# 姿态控制 (内环) - 高频
att_kp = 15.0     # 提高比例增益
att_kd = 8.0      # 大幅增加阻尼 (关键!)
att_ki = 0.0      # 先不使用积分，确保稳定后再加
```

#### 12.2.2 架构改进

1. **使用四元数代替欧拉角**
   - 避免万向节锁
   - 数值更稳定

2. **添加前馈控制**
   - 基于期望轨迹计算前馈推力和力矩
   - 减少反馈控制的负担

3. **分离测试**
   - 先单独测试姿态内环 (固定期望姿态)
   - 再测试位置外环 (固定姿态)
   - 最后联合测试

4. **增加条件积分**
   - 只在误差小于阈值时启用积分
   - 避免大误差时积分饱和

#### 12.2.3 验证流程

```
1. 单机悬停测试
   └─ 验证姿态能否保持水平

2. 单机点对点飞行
   └─ 验证姿态响应和收敛

3. 多机编队静态
   └─ 验证多机同时控制

4. 多机编队动态
   └─ 验证编队切换和移动

5. 加入避障
   └─ 验证避障时的姿态稳定性
```
