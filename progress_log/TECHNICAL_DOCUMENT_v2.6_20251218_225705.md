## 1. 项目概述

### 1.1 项目简介

**多模态无人机集群控制系统** 是一个基于 PySide6 的桌面应用程序，通过融合多种人机交互方式（语音、手势、图像、触屏）实现对无人机集群的直观控制。v2.6 版本新增了 L1 基础动力学模型，为后续 Sim2Real 迁移奠定基础。

### 1.2 核心特性

| 特性 | 描述 |
|------|------|
| **四模态输入** | 语音识别 (Whisper)、手势识别 (MediaPipe)、图像识别 (YOLOv8)、触屏手绘 |
| **无人机指令映射** | 手势→起飞/降落/悬停/编队/高度控制/向前飞行 |
| **手绘编队控制** | 绘制三角形/正方形/圆形/五角星切换编队 |
| **PyQtGraph 3D 可视化** | 原生嵌入的无人机集群 3D 场景渲染 |
| **APF 避障算法** | 人工势场法实现自主避障飞行 |
| **L1 动力学模型** | 基础四旋翼动力学 (质量/推力/阻力/速度限制) |
| **轨迹历史显示** | 渐变色飞行轨迹可视化 |
| **3D 边界围栏** | X/Y/Z 三轴完整地理围栏 |

### 1.3 版本更新亮点 (v2.5 → v2.6)

| 更新项 | v2.5 | v2.6 |
|--------|------|------|
| 运动模型 | 简化速度平滑 | **L1 动力学模型** |
| Z轴边界 | 无 | **8m 高度限制 + 天花板可视化** |
| 轨迹存储 | 200点 | **60点 (~6秒时间衰减)** |
| 动态障碍物 | 可能与静态干涉 | **路径重新规划，避开静态障碍** |

def _execute_takeoff(self):
    """执行起飞 - 垂直上升到指定高度，保持 x,y 位置"""
    self.is_flying = True
    self.in_formation = False  # 起飞后还未进入编队

    # 垂直上升：保持当前 x,y，只改变 z
    for drone in self.drones:
        current_pos = drone.position.copy()
        target = (current_pos[0], current_pos[1], self.current_altitude)
        drone.set_target(target)

## 7. L1 动力学模型 (Sim2Real)

### 7.1 模型概述

v2.6 版本引入 L1 基础四旋翼动力学模型，为后续 Sim2Real 迁移提供基础。

```python
class QuadrotorDynamics:
    """
    L1 基础四旋翼动力学模型

    状态: [x, y, z, vx, vy, vz]
    控制: [ax_cmd, ay_cmd, az_cmd] (期望加速度)

    特性:
    - 质量和重力
    - 推力限制 (最大加速度)
    - 速度限制
    - 线性阻力
    - 半隐式欧拉积分
    """
```

### 7.2 动力学参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| mass | 1.5 kg | 无人机质量 |
| max_thrust | 30.0 N | 最大推力 (~2g) |
| max_velocity | 3.0 m/s | 最大飞行速度 |
| drag_coeff | 0.5 | 线性阻力系数 |
| gravity | 9.81 m/s² | 重力加速度 |
| max_accel | ~10 m/s² | 最大可用加速度 (推力/质量 - 重力) |

### 7.3 控制器参数

| 参数 | 值 | 说明 |
|------|-----|------|
| kp | 2.0 | 位置比例增益 |
| kd | 1.5 | 速度阻尼增益 |

### 7.4 积分方法

采用半隐式欧拉积分 (Semi-implicit Euler)，相比显式欧拉具有更好的能量守恒特性：

```python
def step(self, dt: float, external_accel: np.ndarray = None):
    # 1. 计算期望加速度
    accel_cmd = self.compute_control() if external_accel is None else external_accel

    # 2. 加速度限幅
    accel_cmd = self._clamp_acceleration(accel_cmd)

    # 3. 计算阻力
    drag_force = -self.drag_coeff * self.velocity

    # 4. 总加速度
    total_accel = accel_cmd + drag_force

    # 5. 半隐式欧拉积分
    self.velocity = self.velocity + total_accel * dt  # 先更新速度
    self.velocity = self._clamp_velocity(self.velocity)
    self.position = self.position + self.velocity * dt  # 再更新位置

    return self.position
```

### 7.5 与避障算法集成

```python
# 在动画循环中
if drone.use_dynamics and drone.dynamics:
    # 获取避障速度，转换为期望加速度
    avoidance_vel = drone.compute_avoidance_velocity(obstacles, dynamic_obstacles)
    current_vel = drone.dynamics.velocity
    external_accel = 2.0 * (avoidance_vel - current_vel)  # P控制

    # 动力学积分
    drone.step_dynamics(dt, external_accel)
```

### 7.6 动力学层次规划

| 层次 | 内容 | 状态 |
|------|------|------|
| **L1 (当前)** | 质量 + 推力限制 + 速度限制 + 线性阻力 | ✅ 已实现 |
| L2 | 姿态动力学 (Roll/Pitch/Yaw) + 姿态 PID | 待实现 |
| L3 | 电机动力学 + 气动阻力(二次项) + 传感器噪声 | 待实现 |

### 9.3 颜色渐变算法

```python
def _update_trajectory_visual(self):
    n = len(self._trajectory_points)
    colors = np.zeros((n, 4))

    for i in range(n):
        # 透明度渐变: 旧(0.2) → 新(1.0)
        alpha = 0.2 + 0.8 * (i / max(1, n - 1))
        # 亮度渐变: 旧(60%) → 新(100%)
        brightness = 0.6 + 0.4 * (i / max(1, n - 1))

        colors[i] = [
            self.color[0] * brightness,
            self.color[1] * brightness,
            self.color[2] * brightness,
            alpha
        ]

    self._trajectory_visual.setData(pos=pts, color=colors)
```

### A. 操作流程

| 步骤 | 手势 | 效果 |
|------|------|------|
| 1 | 张开手掌 | 集群起飞 (垂直上升，悬停) |
| 2 | ILY手势 (三指) | 进入编队飞行 |
| 3 | V形手势 (剪刀手) | 编队向前飞行 5 米 |
| 4 | 手绘形状 | 切换编队类型 |
| 5 | 握拳 | 集群降落 |
