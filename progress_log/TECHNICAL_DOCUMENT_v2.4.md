## 1. 项目概述

### 1.1 项目简介

**多模态无人机集群控制系统** 是一个基于 PySide6 的桌面应用程序，通过融合多种人机交互方式（语音、手势、图像、触屏）实现对无人机集群的直观控制。

### 1.2 核心特性

| 特性 | 描述 |
|------|------|
| **四模态输入** | 语音识别 (Whisper)、手势识别 (MediaPipe)、图像识别 (YOLOv8)、触屏手绘 |
| **无人机指令映射** | 手势→起飞/降落/悬停/编队/高度控制/向前飞行 |
| **手绘编队控制** | 绘制三角形/正方形/圆形/五角星切换编队 |
| **PyQtGraph 3D 可视化** | 原生嵌入的无人机集群 3D 场景渲染 |
| **APF 避障算法** | 人工势场法实现自主避障飞行 |
| **可折叠状态卡片** | 实时显示每架无人机位置、电量、信号、速度 |
| **编队向前飞行** | V形手势触发编队整体向前避障飞行 |

## 6. 无人机行为逻辑

### 6.1 状态机 (v2.3 重构)

```
地面待命 --[起飞]--> 悬停中 --[编队指令]--> 编队飞行
    ^                  |                      |
    |                  v                      v
    +----[降落]--------+--------[降落]--------+
```

### 6.2 状态说明

| 状态 | 显示 | 颜色 | 说明 |
|------|------|------|------|
| 地面待命 | "地面待命" | 灰色 | 无人机在地面随机位置 |
| 悬停中 | "悬停中" | 绿色 | 起飞后保持原位悬停 |
| 编队飞行 | "编队飞行" | 蓝色 | 进入编队队形 |

### 6.3 起飞逻辑 (v2.3 修改)

**之前 (v2.2)**:
- 初始位置为编队队形
- 起飞直接飞到编队位置

**现在 (v2.3)**:
- 初始位置**随机分布**在中心3m半径内
- 起飞**垂直上升**到1.5m，保持x,y位置不变
- 只有收到**编队指令**才进入编队队形

```python
def _execute_takeoff(self):
    """执行起飞 - 垂直上升到指定高度，保持 x,y 位置"""
    self.is_flying = True
    self.in_formation = False  # 起飞后还未进入编队

    # 垂直上升：保持当前 x,y，只改变 z
    for drone in self.drones:
        current_pos = drone.position.copy()
        target = (current_pos[0], current_pos[1], self.current_altitude)
        drone.set_target(target)
```

### 6.4 编队向前飞行 (新增)

```python
def _execute_move_forward(self, distance: float = 5.0):
    """执行编队向前飞行"""
    if not self.is_flying or not self.in_formation:
        return  # 必须在编队飞行状态下才能移动

    # 更新编队中心位置（Y轴正方向为前方）
    new_center = (self.center[0], self.center[1] + distance)
    self.center = new_center

    # 生成新的编队位置
    positions = self._generate_formation_positions(...)
    for drone, pos in zip(self.drones, positions):
        drone.set_target(pos)
```

**边界约束逻辑**:
```python
# 实时位置约束
drone.position[0] = np.clip(drone.position[0], -self.boundary_limit, self.boundary_limit)
drone.position[1] = np.clip(drone.position[1], -self.boundary_limit, self.boundary_limit)
drone.position[2] = max(0.0, drone.position[2])  # 不能低于地面

# 编队中心约束
max_center = self.boundary_limit - self.formation_radius - 1.0
new_y = np.clip(new_y, -max_center, max_center)
```

def _attractive_force(self, current, target):
