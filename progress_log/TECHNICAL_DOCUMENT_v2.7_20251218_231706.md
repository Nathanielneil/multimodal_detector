## 1. 项目概述

### 1.1 项目简介

**多模态无人机集群控制系统** 是一个基于 PySide6 的桌面应用程序，通过融合多种人机交互方式（语音、手势、图像、触屏）实现对无人机集群的直观控制。

**v2.7 版本亮点**: 实现了 L2 姿态动力学模型，包含完整的 12 自由度状态空间、双环控制架构（位置外环 + 姿态内环）、以及实时姿态可视化，为 Sim2Real 迁移奠定坚实基础。

### 1.2 核心特性

| 特性 | 描述 |
|------|------|
| **四模态输入** | 语音识别 (Whisper)、手势识别 (MediaPipe)、图像识别 (YOLOv8)、触屏手绘 |
| **无人机指令映射** | 手势→起飞/降落/悬停/编队/高度控制/向前飞行 |
| **手绘编队控制** | 绘制三角形/正方形/圆形/五角星切换编队 |
| **PyQtGraph 3D 可视化** | 原生嵌入的无人机集群 3D 场景渲染 |
| **APF 避障算法** | 人工势场法实现自主避障飞行 |
| **L2 姿态动力学** | 完整 12DOF 动力学 + 双环 PID 控制 |
| **姿态可视化** | 无人机模型实时倾斜显示 |
| **3D 边界围栏** | X/Y/Z 三轴完整地理围栏 |
| **轨迹历史显示** | 渐变色飞行轨迹可视化 |

### 1.3 版本更新亮点 (v2.6 → v2.7)

| 更新项 | v2.6 | v2.7 |
|--------|------|------|
| 动力学模型 | L1 (6DOF: 位置+速度) | **L2 (12DOF: +姿态+角速度)** |
| 控制架构 | 单环 PD | **双环: 位置PD + 姿态PID** |
| 姿态状态 | 无 | **Roll/Pitch/Yaw + p/q/r** |
| 可视化 | 仅位置 | **位置 + 姿态倾斜** |
| 力学模型 | 直接加速度 | **推力矢量 + 旋转矩阵** |

### 7.2 L2 状态空间

```
状态向量 x = [x, y, z, vx, vy, vz, φ, θ, ψ, p, q, r]ᵀ

位置状态 (世界坐标系):
- x, y, z     : 位置 (m)
- vx, vy, vz  : 速度 (m/s)

姿态状态:
- φ (roll)    : 横滚角 (rad)
- θ (pitch)   : 俯仰角 (rad)

- p, q, r     : 机体角速度 (rad/s)
```

### 7.4 动力学方程

**位置动力学**:
```
d(pos)/dt = vel
d(vel)/dt = R · [0, 0, T/m]ᵀ - [0, 0, g]ᵀ - c_d · vel
```

**姿态动力学**:
```
d(euler)/dt = W(φ, θ) · ω
I · d(ω)/dt = τ - ω × (I · ω)
```

其中:
- R: 旋转矩阵 (ZYX 欧拉角顺序)
- T: 总推力
- W: 欧拉角速率矩阵
- τ: 控制力矩
- ω × (I·ω): 陀螺力矩

### 7.5 旋转矩阵 (ZYX 欧拉角)

```python
def _rotation_matrix(roll, pitch, yaw):
    cr, sr = cos(roll), sin(roll)
    cp, sp = cos(pitch), sin(pitch)
    cy, sy = cos(yaw), sin(yaw)

    R = [
        [cy*cp, cy*sp*sr - sy*cr, cy*sp*cr + sy*sr],
        [sy*cp, sy*sp*sr + cy*cr, sy*sp*cr - cy*sr],
        [-sp,   cp*sr,            cp*cr]
    ]
    return R
```

### 7.6 控制架构详解

**外环 (位置控制器)**:
```python
# 输入: 目标位置, 当前位置/速度
# 输出: 期望姿态角 + 推力

pos_error = target_pos - current_pos
accel_des = kp * pos_error - kd * velocity + [0, 0, g]

thrust = mass * |accel_des|

# 从期望加速度计算期望姿态
desired_pitch = atan2(ax_body, g + az)
desired_roll = atan2(-ay_body, sqrt(ax² + (g+az)²))
```

**内环 (姿态PID控制器)**:
```python
# 输入: 期望姿态, 当前姿态/角速度
# 输出: 控制力矩

roll_error = desired_roll - roll
torque_x = (kp * roll_error - kd * p + ki * integral) * Ixx

pitch_error = desired_pitch - pitch
torque_y = (kp * pitch_error - kd * q + ki * integral) * Iyy

yaw_error = desired_yaw - yaw  # 归一化到 [-π, π]
torque_z = (kp_yaw * yaw_error - kd_yaw * r) * Izz
```

### 7.7 积分方法

采用**半隐式欧拉积分** (Symplectic Euler):

```python
# 1. 姿态动力学
angular_accel = (torque - cross(omega, I*omega)) / I
omega_new = omega + angular_accel * dt
euler_new = euler + W(euler) @ omega_new * dt

# 2. 位置动力学
R = rotation_matrix(euler_new)
thrust_world = R @ [0, 0, thrust/mass]
accel = thrust_world - [0, 0, g] - drag * velocity
velocity_new = velocity + accel * dt
position_new = position + velocity_new * dt
```

```python
def _update_transform(self):
    # 获取姿态角
    roll, pitch, yaw = self.dynamics.attitude

    # 计算旋转矩阵
    R = rotation_matrix(roll, pitch, yaw)

    # 对每个部件应用旋转
    for component in [body, arms, motors, rotors, legs]:
```

```python
class QuadrotorDynamics:
    """L2 四旋翼动力学模型 - 含姿态动力学"""

    def __init__(
        self,
        mass: float = 1.5,
        max_thrust: float = 30.0,
        max_velocity: float = 5.0,
        drag_coeff: float = 0.3,
        gravity: float = 9.81,
        inertia: tuple = (0.02, 0.02, 0.04),
        max_tilt: float = 0.5,
        max_yaw_rate: float = 2.0,
    )

    # 状态属性
    position: np.ndarray      # [x, y, z]
    velocity: np.ndarray      # [vx, vy, vz]
    attitude: np.ndarray      # [roll, pitch, yaw]
    angular_velocity: np.ndarray  # [p, q, r]

    # 方法
    def set_state(self, position, velocity=None, attitude=None, angular_velocity=None)
    def set_target(self, target, yaw=None)
    def compute_position_control(self) -> tuple  # (roll, pitch, thrust)
    def compute_attitude_control(self, roll, pitch, dt) -> np.ndarray  # torque
    def step(self, dt, external_accel=None) -> np.ndarray  # new position
    def get_state(self) -> dict
    def get_attitude(self) -> np.ndarray
    def is_at_target(self, tolerance=0.1) -> bool
```
