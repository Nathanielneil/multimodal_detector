## 1. 项目概述

### 1.1 项目简介

**多模态无人机集群控制系统** 是一个基于 PySide6 的桌面应用程序，通过融合多种人机交互方式（语音、手势、图像、触屏）实现对无人机集群的直观控制。

**v2.9 版本亮点**: 新增集群数量动态控制功能，用户可以通过界面按钮实时增减无人机数量（1-12架），且操作不会影响现有无人机的位置状态。

### 1.2 核心特性

| 特性 | 描述 | 状态 |
|------|------|------|
| **四模态输入** | 语音识别 (Whisper)、手势识别 (MediaPipe)、图像识别 (YOLOv8)、触屏手绘 | ✅ |
| **无人机指令映射** | 手势→起飞/降落/悬停/编队/高度控制/向前飞行 | ✅ |
| **手绘编队控制** | 绘制三角形/正方形/圆形/五角星切换编队 | ✅ |
| **PyQtGraph 3D 可视化** | 原生嵌入的无人机集群 3D 场景渲染 | ✅ |
| **APF 避障算法** | 人工势场法实现自主避障飞行 | ✅ |
| **L1 动力学模型** | 6DOF 位置+速度, PD控制 | ✅ |
| **3D 边界围栏** | X/Y/Z 三轴完整地理围栏 | ✅ |
| **轨迹历史显示** | 渐变色飞行轨迹可视化 | ✅ |
| **集群数量控制** | 动态增减无人机数量 (1-12架) | ✅ **v2.9 新增** |

## 3. 集群数量控制功能

### 3.1 UI 组件

**位置**: 右侧栏，"命令历史"和"无人机状态"之间

```
┌─────────────────────────┐
│     命令历史            │
├─────────────────────────┤
│ ✈ 集群控制              │  ← 新增卡片
│ 当前: 6 架    [-] [+]   │
├─────────────────────────┤
│     无人机状态          │
│     UAV-0 ...           │
└─────────────────────────┘
```

**按钮样式**:
- **[+] 增加按钮**: 绿色背景 (#e8f5e9)，深绿文字 (#2e7d32)
- **[-] 减少按钮**: 红色背景 (#ffebee)，深红文字 (#c62828)
- 按钮尺寸: 36x36px，圆角 8px，字体 24px 粗体

### 3.2 数量限制

| 参数 | 值 |
|------|-----|
| 最小数量 | 1 架 |
| 最大数量 | 12 架 |
| 默认数量 | 6 架 |

### 3.3 行为逻辑

#### 3.3.1 增加无人机 ([+])

```python
def set_drone_count(self, count: int):
    if count > old_count:
        # 现有无人机保持原位
        # 新增无人机:
        if self.is_flying:
            # 飞行中 → 加入当前编队位置
            pos = formation_positions[new_id]
        else:
            # 地面待命 → 随机位置 (中心半径 0.5-2.5m)
            pos = random_ground_position()
        new_drone.set_position(pos)
```

#### 3.3.2 减少无人机 ([-])

```python
def set_drone_count(self, count: int):
    if count < old_count:
        # 现有无人机保持原位
        # 只移除末尾的无人机
        while len(self.drones) > count:
            drone = self.drones.pop()
            drone.remove()
```

### 3.4 联动效果

1. **3D 视图**: 无人机数量实时更新
2. **状态栏标签**: 自动更新 "无人机: X架"
3. **右侧状态卡片**: 自动重建卡片列表
4. **编队飞行**: 飞行中增加无人机会自动加入编队

### 3.5 代码位置

| 文件 | 类/方法 | 说明 |
|------|---------|------|
| `ui/main_window.py` | `_create_swarm_control_card()` | 创建控制卡片 UI |
| `ui/main_window.py` | `_on_add_drone()` | 增加按钮回调 |
| `ui/main_window.py` | `_on_remove_drone()` | 减少按钮回调 |
| `ui/main_window.py` | `_rebuild_drone_status_cards()` | 重建状态卡片 |

## 4. 当前动力学模型 (L1)

### 4.1 模型概述

| 属性 | 值 |
|------|-----|
| 状态维度 | 6 DOF (位置 + 速度) |
| 控制方式 | PD 位置控制 |
| 积分方法 | 半隐式欧拉 |
| 稳定性 | ✅ 稳定 |

### 4.2 状态空间

```
状态向量 x = [x, y, z, vx, vy, vz]ᵀ
```

### 4.3 动力学参数

| 参数 | 符号 | 默认值 | 说明 |
|------|------|--------|------|
| 质量 | m | 1.5 kg | 无人机质量 |
| 最大推力 | F_max | 30.0 N | ~2g |
| 最大速度 | v_max | 5.0 m/s | 速度限制 |
| 阻力系数 | c_d | 0.3 | 线性阻力 |
| 位置增益 | kp | 2.0 | PD 控制 |
| 速度增益 | kd | 1.5 | PD 控制 |

## 7. 手势指令系统

| 手势 | 检测规则 | 无人机指令 | 说明 |
|------|----------|-----------|------|
| 张开手掌 | 所有手指伸直 | 集群起飞 | 垂直上升到1.5m |
| 握拳 | 所有手指弯曲 | 集群降落 | 垂直下降到地面 |
| 食指向上 | 仅食指伸直 | 集群悬停 | 保持当前位置 |
| ILY 手势 | 大拇指+食指+小指伸直 | 编队飞行 | 进入当前编队 |
| V形手势 | 食指+中指伸直 | 向前飞行 | 编队向前移动5m |
| OK 手势 | 大拇指食指接触 | 指令确认 | - |
| 竖起大拇指 | 大拇指向上 | 高度上升 | +0.5m |
| 向下大拇指 | 大拇指向下 | 高度下降 | -0.5m |
