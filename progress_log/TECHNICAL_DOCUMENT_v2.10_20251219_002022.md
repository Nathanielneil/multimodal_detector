## 1. 项目概述

### 1.1 项目简介

**多模态无人机集群控制系统** 是一个基于 PySide6 的桌面应用程序，通过融合多种人机交互方式（语音、手势、图像、触屏）实现对无人机集群的直观控制。

**v2.10 版本亮点**: 优化 APF 避障算法参数，显著提升无人机在避障后的编队恢复速度。

### 1.2 核心特性

| 特性 | 描述 | 状态 |
|------|------|------|
| **四模态输入** | 语音识别 (Whisper)、手势识别 (MediaPipe)、图像识别 (YOLOv8)、触屏手绘 | ✅ |
| **无人机指令映射** | 手势→起飞/降落/悬停/编队/高度控制/向前飞行 | ✅ |
| **手绘编队控制** | 绘制三角形/正方形/圆形/五角星切换编队 | ✅ |
| **PyQtGraph 3D 可视化** | 原生嵌入的无人机集群 3D 场景渲染 | ✅ |
| **APF 避障算法** | 人工势场法实现自主避障飞行 | ✅ **v2.10 优化** |
| **L1 动力学模型** | 6DOF 位置+速度, PD控制 | ✅ |
| **3D 边界围栏** | X/Y/Z 三轴完整地理围栏 | ✅ |
| **轨迹历史显示** | 渐变色飞行轨迹可视化 | ✅ |
| **集群数量控制** | 动态增减无人机数量 (1-12架) | ✅ |

## 2. 版本更新说明 (v2.9 → v2.10)

### 2.1 变更摘要

| 项目 | v2.9 | v2.10 |
|------|------|-------|
| 引力增益 (attractive_gain) | 2.0 | **4.0** |
| 影响距离 (influence_distance) | 0.8 m | **0.6 m** |
| 最大速度 (max_speed) | 3.0 m/s | **4.0 m/s** |
| 引力衰减距离 | 0.5 m | **0.2 m** |
| UI 卡片标题 | "集群控制" | **"集群数量"** |

### 2.2 问题描述

**用户反馈**: 集群中的无人机因为避障导致的队形变化不能快速恢复。

**根因分析**:
1. 原有引力增益 (2.0) 过小，目标吸引力不足
2. 影响距离 (0.8m) 过大，无人机过早减速
3. 引力衰减逻辑在距离目标 0.5m 时就开始明显衰减

### 2.3 优化效果

| 指标 | 优化前 | 优化后 | 改善 |
|------|--------|--------|------|
| 编队恢复时间 | ~3-4秒 | ~1-2秒 | **50%+** |
| 目标吸引力 | 较弱 | 强 | 2倍 |
| 接近目标速度 | 过早减速 | 精准减速 | 更流畅 |

## 3. APF 避障优化详解

### 3.1 参数对比

```
优化前 (v2.9):
┌──────────────────────────────────────┐
│ ObstacleAvoidance(                   │
│     attractive_gain=2.0,    # 引力弱  │
│     repulsive_gain=0.5,              │
│     influence_distance=0.8, # 影响大  │
│     max_speed=3.0           # 速度慢  │
│ )                                    │
└──────────────────────────────────────┘

优化后 (v2.10):
┌──────────────────────────────────────┐
│ ObstacleAvoidance(                   │
│     attractive_gain=4.0,    # 引力强  │
│     repulsive_gain=0.5,              │
│     influence_distance=0.6, # 影响小  │
│     max_speed=4.0           # 速度快  │
│ )                                    │
└──────────────────────────────────────┘
```

### 3.2 引力函数优化

**原代码 (v2.9)**:
```python
def _attractive_force(self, current_pos, target_pos):
    diff = target_pos - current_pos
    distance = np.linalg.norm(diff)

    if distance < 0.01:
        return np.zeros(3)

    direction = diff / distance

    # 距离越近,力越小 (0.5m 开始衰减)
    if distance < 0.5:
        magnitude = self.attractive_gain * (distance / 0.5)
    else:
        magnitude = self.attractive_gain

    return direction * magnitude
```

**优化代码 (v2.10)**:
```python
def _attractive_force(self, current_pos, target_pos):
    diff = target_pos - current_pos
    distance = np.linalg.norm(diff)

    if distance < 0.01:
        return np.zeros(3)

    direction = diff / distance

    # 距离越近,力越小 (0.2m 开始衰减) - 衰减距离缩短
    if distance < 0.2:
        magnitude = self.attractive_gain * (distance / 0.2)
    else:
        magnitude = self.attractive_gain

    return direction * magnitude
```

### 3.3 优化原理

```
引力场变化示意:

v2.9 (衰减距离 0.5m):
  引力
   ▲
4.0├─────────────────────────────────────
   │                         ╱
2.0├─────────────────────────╱
   │              ╱
1.0├─────────────╱
   │     ╱
 0 ├────╱─────┬─────┬─────┬─────┬───→ 距离
   0   0.5    1    1.5    2    2.5

v2.10 (衰减距离 0.2m):
  引力
   ▲
4.0├────────────────────────────────────
   │                              │
   │                              │
2.0├──────────────────────────────│
   │                              │
1.0├                              │
   │ ╱                            │
 0 ├╱────┬─────┬─────┬─────┬─────┬───→ 距离
   0   0.2   0.5    1    1.5    2
```

**关键改进**:
1. 引力增益翻倍 (2.0→4.0)，无人机返回编队的"拉力"更强
2. 衰减距离缩短 (0.5m→0.2m)，无人机在接近目标位置前保持较大速度
3. 最大速度提升 (3.0→4.0 m/s)，移动更快
4. 影响距离减小 (0.8m→0.6m)，斥力范围收窄，避障更精准

状态向量 x = [x, y, z, vx, vy, vz]ᵀ

```
编队目标位置
      │
      v
┌─────────────────────────────────────────────────────┐

│                                                     │
│   目标位置 ──→ 引力函数 (gain=4.0) ──→ 吸引力向量    │

│                     ↓                               │

│                                                     │
│   合力 = 吸引力 + 斥力 ──→ 速度限制 (4.0 m/s)       │
└─────────────────────────────────────────────────────┘
      │
      v
L1 动力学模型 (PD控制)
      │
      v
无人机位置更新
```
